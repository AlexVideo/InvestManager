Чтобы Run (F5) из Cursor работал без ошибки пути:

1. Запустите create_cursor_workspace.bat (из этой папки, при ошибке — правый клик → Запуск от имени администратора).
   Появится папка C:\IM — это та же папка проекта.

2. В Cursor: File → Open Folder (Файл → Открыть папку).
   Выберите именно C:\IM (не Documents\InvestManager-main).

3. Дальше работайте как обычно: открываете app.py, жмёте Run (треугольник или F5).
   Путь будет C:\IM\... — без кириллицы, ошибка пропадёт.

Важно: пока открыта папка с путём ...\Пивоварка\... — Cursor будет подставлять путь с ошибкой. Нужно открыть C:\IM.
